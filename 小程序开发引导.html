线A 小程序账号 + 认证→线C 微信支付商户号→顾客能付款

步骤 4 · 域名 + ICP 备案 + HTTPS你做我做

这是全流程最慢、也最容易被忽略的一步。小程序只允许请求已备案的 HTTPS 域名，不允许 IP、不允许 http。 我们的后端现在跑在 http://124.223.16.159（没有域名）——所以现在真机连不上，只能在开发者工具里预览。
  1. 买域名：腾讯云 / 阿里云都可，建议在腾讯云买（服务器也是腾讯云，备案更顺）。域名要实名认证（约 1–3 天）。
  2. 提交 ICP 备案：腾讯云备案控制台。腾讯云服务器实例可以生成「备案授权码」。材料：主体证件、法人/负责人身份证、网站负责人人脸核验（手机 App）、真实性核验单。免费，时长以管局为准（常见 1–20 个工作日）。
  3. DNS 解析：备案通过后加一条 A 记录指向 124.223.16.159。
  4. HTTPS 证书：腾讯云可申请免费 DV 证书（或我用 Let's Encrypt）。
  5. Nginx 加一个 server 块（我做）：server_name 你的域名; + 443 + 证书 → 反代到现有的 127.0.0.1:8093。
    ✅ 不会和同机其它服务抢端口：80/443 已被占用没问题，Nginx 靠 server_name（域名） 区分站点——这正是现在 IP 直连入口的做法（deploy/host-nginx-ip.conf）。等域名到位我们切到 deploy/host-nginx.conf。
这一步做完的样子：浏览器打开 https://你的域名/admin 能进管理端，锁标志正常。 你要给我：备案通过的域名。
